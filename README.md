# RegistryChain DApp

Sistema descentralizado para registro y verificación de equipos tecnológicos utilizando Blockchain Ethereum.

## Tecnologías utilizadas

- Angular 21
- TypeScript
- Ethers.js
- Solidity
- MetaMask
- Ethereum Sepolia Testnet

## Funcionalidades

### Registro de equipos
Permite registrar equipos tecnológicos en la blockchain mediante:
- Número de serie
- Tipo
- Marca
- Modelo
- Propietario

### Consulta de equipos
Permite verificar la información registrada en blockchain mediante el número de serie.

### Actualización de estado
Permite actualizar el estado de un equipo:
- Activo
- Extraviado
- Robado
- Recuperado
